Methodology

Every number here is reproducible on any H100. If you get different results, we want to know.

Load Test

  • Script: zia_load_test.py
  • Arrival: Poisson process, λ = 16.7 req/s
  • Scenarios: 8 real support messages, randomly rotated
  • Measurement: End-to-end wall clock, first byte to last token
  • Duration: 60 seconds continuous
  • Latency: Percentiles from sorted array of all response times

Throughput Benchmark (TRT-LLM AWQ)

  • Script: trtllm_bench_awq.py
  • Engine: TRT-LLM 0.16 · AWQ W4A16 · multiple_profiles · H100-SXM
  • Calibration: cnn_dailymail · 512 batches · max_seq_len 512
  • Prompts: Mixed short/medium/long (5–113 tokens) — no repeated strings
  • Calculation: Total output tokens ÷ avg wall-clock over 4 rounds
  • Batches tested: 1, 8, 32, 64, 128 concurrent requests

Cost Calculation

  • H100 spot price: $2.40 / hr (GCP a3-highgpu-1g, Feb 2026)
  • Token pricing: Monthly GPU cost ÷ monthly token throughput
  • GPT-4o pricing: $5 / $15 per 1M input / output tokens
  • Together AI pricing: ~$0.20 per 1M tokens (Llama 3 8B)
  • Message assumption: 200 input + 100 output tokens per message

Quality Evaluation

  • Evaluator: Human (founder), blind to model settings
  • Inputs: One adversarial input per intent category (27 total)
  • Escalation test: 5 extreme cases (threats, repeated failures)
  • Hallucination test: Checked for invented order IDs or policies
  • Limitation: Single evaluator — automated RLHF scoring in progress
